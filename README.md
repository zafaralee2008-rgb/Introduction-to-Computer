- Mainframe Computer

## History of Computers

### Early Tools and Mechanical Calculators
- **Abacus** (c. 2400 BCE): one of the first calculating aids
- **Pascaline** (1642): Blaise Pascal's adding machine
- **Analytical Engine** (1837): Charles Babbage's design for a general-purpose computer
- **Ada Lovelace** (1843): wrote the first algorithm for a machine

### Generations of Computers

| Generation | Period | Key Technology |
|---|---|---|
| 1st | 1940-1956 | Vacuum tubes |
| 2nd | 1956-1963 | Transistors |
| 3rd | 1964-1971 | Integrated circuits |
| 4th | 1971-present | Microprocessors |
| 5th | Present and beyond | AI, quantum computing |
